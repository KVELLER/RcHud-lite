# RcHud-lite
A stripped-down version of RcHud by The0x539 compatible with the ULTRA_REVAMP update. Unlike the original version, it doesn't have any functionality to show your currently equipped weapon and arm since I felt it was redundant (and couldn't be bothered to get it to work). Everything else, including stamina colors, high visibility overheal, persistent HP and the Railcannon meter is functional.

For more information, including instructions on how to install it, please go to the [original repository](https://github.com/The0x539/ULTRAKILL-Mods/tree/trunk/RcHud).
